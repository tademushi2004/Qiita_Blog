## 1. ゲームの面白さを際立たせる「思考のレンズ」

![ゲーム開発の大統一理論_02-00_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/8158073d-c341-438a-a9ec-8ce0f376b485.avif)

こんにちは。前回は、ゲームの面白さの正体が「8つの基礎本能」であり、プレイヤーを熱狂させるには「報酬の予感（期待値）」を下げないことが重要だというお話をしました。
退屈なノイズが一度でも混ざると、強化学習の数式が示すように、プレイヤーの期待値は急落し二度と戻ってきません。

「なるほど、じゃあノイズをなくして本能を刺激しまくればいいんだな！」と意気込んで開発画面に向かっても、なかなか手が動かないのではないでしょうか？
実は、人間の本能という **「素晴らしい被写体」** があっても、ただ正面からシャッターを切るだけでは、ありふれた凡庸なゲーム（写真）にしかなりません。

名作と呼ばれるゲームは、まるでプロのカメラマンが **「思考のレンズ」** を付け替えるように、様々なアングルから被写体を捉えています。
余計な背景をフレームから外す（引き算）、別の被写体を一緒に写し込む（新たな結びつけ）、全く違うアングルから覗き込む（まったく新しい価値）……。

**実は、ゲームの面白さを極限まで際立たせるためには、常識を疑い、視点を切り替えるための「問い（レンズ）」が必要不可欠** なのです。

## 2. ゲームを洗練する「問い」の力（SEIQ）

![ゲーム開発の大統一理論_02-01_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/255e7f91-1209-4946-bf39-81355cf42ab9.avif)

この「問い」の重要性は、科学的な研究によっても裏付けられています。
INSEAD（欧州経営大学院）のハル・グレガーセンらが執筆した論文『The Elements of Value: Measuring—and Delivering—What Consumers Really Want』 [^1] では、「イノベーションを起こす優れたリーダーやクリエイターは、常に鋭い『質問』を投げかける能力が高い」という事実が提示されています。問う力こそが、イノベーションの源泉なのです。

では、具体的にどんな「問い」を投げかければよいのでしょうか。
ここで、「イノベーションに欠かせない7つの本質的な質問（SEIQ）」というフレームワークを導入しましょう [^2]。
このSEIQは、ストラテジストのビル・オコナーがカリフォルニア大学バークレー校との共同研究で開発したものであり、その元論文は『Cracking the DNA of 'Breakthrough Innovation' Success』です [^3]。

この7つの質問は、ゲームのノイズを削ぎ落とし、新たな本能の訴求軸を見つけるための **「思考のレンズ」** として完璧に機能します。全体像と、それが生み出すゲームデザインの発想例を見てみましょう。

| SEIQの問い | 質問の狙い（視点の切り替え） | ゲームにおける実践・発想例 |
| :--- | :--- | :--- |
| **Q1. 新たな視点** | 私の商品を新たな視点で見ることは可能だろうか？ | 敵を倒すゲームではなく、敵から隠れ、逃げ続けるゲームにできないか？（『Outlast』） |
| **Q2. 新しい方法** | 私の商品を新しい方法で使うことはできるか？ | コントローラーを捨てて、自らの身体の動きで操作できないか？（『リングフィット アドベンチャー』） |
| **Q3. 時間や場所** | 私の商品が機能する時間や場所を変えることはできるだろうか？ | プレイヤーが寝ている時間（非起動時）にだけ進むゲームにできないか？（『Pokémon Sleep』） |
| **Q4. 新たな結びつけ** | 私の商品に何かを新たに結びつけることができるだろうか？ | 単調な入国審査の作業に道徳的ジレンマを結びつけられないか？（『Papers, Please』） |
| **Q5. デザインや性能** | 私の商品のデザインや性能を変える（削る）ことはできないだろうか？ | 攻撃ボタンや複雑な移動操作を完全に無くせないか？（『Vampire Survivors』） |
| **Q6. 新しさ** | 私の商品に”新しさ”を感じるものを加えられないだろうか？ | レトロなドット絵の世界に、最新の物理演算によるピクセル単位の破壊表現を加えられないか？（『Noita』） |
| **Q7. まったく違う価値** | 私の商品のまったく違う価値を想像できないだろうか？ | 戦闘で誰も殺さなくていいRPGという価値は作れないか？（『Undertale』） |

今回はこの7つの問いの中から、特にインディーゲームの歴史的傑作を生み出した **「Q7」「Q5」「Q4」** の3つのレンズに焦点を当てて、彼らがどのように本能を刺激したのかを解き明かしていきます。

### まったく違う価値への問い（SEIQ 7）：『Undertale』

![ゲーム開発の大統一理論_02-02_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/cf9bb84c-40ae-46eb-a075-2adc79896174.avif)

*出典：[Undertale 公式プレスキット](https://www.igdb.com/games/undertale/presskit) / ©Toby Fox*

*   **SEIQ 7の問い** ：「私の商品のまったく違う価値を想像できないだろうか？」

世界中で大ヒットしたインディーRPG『Undertale』の開発者であるToby Fox氏は、開発の初期段階で **「RPGはモンスターを殺すしかないのか？」** という根源的な問いを立てました [^4]。そして、「誰も死ななくていい優しいRPG」という、それまでの常識を覆すまったく新しい価値を創造したのです。

従来のRPGは、敵を倒すことによる **「進める本能」** や、レベルを上げて強くなる **「高める本能」** に依存していました。しかしToby Fox氏は、暴力によるこれらの本能の充足を思い切って捨て去る（フレームから外す）選択をしたのです。

その代わりに、敵と対話し平和的に解決するという新たな選択肢によって **「決する本能」「物語る本能」** を刺激し、さらにユニークなキャラクターたちとの心温まる触れ合いによって **「属する本能」** を満たしました。暴力という絶対的な要素を手放したことで、別ベクトルの本能のコンボが炸裂し、プレイヤーの心を激しく揺さぶる結果となったのです。

### デザインと性能への問い（SEIQ 5）：『Vampire Survivors』

![ゲーム開発の大統一理論_02-03_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/e2683091-5db1-4ecc-9928-5bca4d646ac2.avif)

*出典：[Vampire Survivors 公式プレスキット](https://www.igdb.com/games/vampire-survivors/presskit)*

*   **SEIQ 5の問い** ：「私の商品のデザインや性能を変える（不要なものを極限まで削ぎ落とす）ことはできないだろうか？」

ローグライトアクションの金字塔『Vampire Survivors』は、まさに **「何を削れば、面白さは最も純化するのか？」** という引き算の美学を極めた作品です。

このゲームには、アクションゲームの常識である「攻撃ボタン」が存在しません。複雑な移動テクニックも、難解なストーリーもありません。これらの一見必要そうな要素（ノイズ）を徹底的に削ぎ落とすことで、プレイヤーの認知や操作のコストを下げ、 **「安らぐ本能」** を極大化させました [^5]。

面倒な操作がなくなったことで、プレイヤーの脳の余力は、無数の敵を倒し宝石をかき集める **「進める・有する本能」** 、レベルアップして自機を強化する **「高める本能」** 、ランダムに提示される武器から最強のビルドを構築する **「決する本能」** に100%割り当てられます。
邪魔な背景をすべて切り捨て、味わいたい本能のループだけにピントを合わせたことで、圧倒的な没入感を生み出したのです。

### 新たな結びつけへの問い（SEIQ 4）：『Papers, Please』

![ゲーム開発の大統一理論_02-04_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/876167d9-5e74-4376-9eed-f72b25bf113b.avif)

*出典：[Papers, Please 公式プレスキット](https://papersplea.se/presskit/)*

*   **SEIQ 4の問い** ：「私の商品に何かを新たに結びつけることができるだろうか？」

架空の共産主義国家の入国審査官となる『Papers, Please』の開発者、ルーカス・ポープ氏は、 **「単調な入国審査の『作業』に、別の要素を結びつけて面白くできないだろうか？」** と問いました [^6]。

書類の矛盾を見抜いてハンコを押すだけの単純作業は、それ単体では退屈であり、前回解説した数式モデルでは「期待値を急落させるノイズ（評価の低いエピソード）」になりかねません。
しかし彼はそこに、薄給で「家族を養わなければならない」という重圧（ **有する・属する本能** ）と、目の前の哀れな入国者を通すか否かで「他者の運命を決める」という道徳的ジレンマ（ **物語る・決する本能** ）を掛け合わせました。
さらに、見逃せばテロリストが侵入してゲームオーバーになるかもしれないというスリル（ **安らぐ本能** の一種である危険の管理）を結びつけたのです。

つまらないはずの作業に、別の強烈な感情（本能）を写し込んだことで、ただのハンコ押しが「手に汗握る究極の決断」へと変貌しました。これはまさに、神がかり的なアングルの切り替えだと言えます。

## 3. あなただけの「面白いゲーム」を作るために

![ゲーム開発の大統一理論_02-05_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/fbacbca1-59e3-454c-9bf3-e0c2a3417c73.avif)

全2回にわたって、進化論と脳科学の観点から「ゲームの面白さ」を解き明かしてきました。

人間の脳は原始時代から変わっていません。だからこそ、ゲームには **「8つの基礎本能」** を満たす必要があります。そして、その期待値を下げないためには、退屈なノイズを排除し **「報酬の予感」** をキープする厳格な設計（数式）が求められます。これが、あなたが進むべきゲーム開発というダンジョンの **「地図」** です。

そして、闇雲に要素を詰め込んで凡庸なゲームにならないためには、常識を疑い、視点を切り替える **「問いのレンズ（SEIQ）」** が必要です。これが、ダンジョンを切り開くための **「道具」** となります。

優れた地図と道具を手に入れた今、あとはあなた自身のダンジョンへ潜るだけです。
ぜひ「問いの力」を武器にして、プレイヤーの脳を熱狂させる、あなただけの「最高に面白いゲーム」を生み出してください！
