## 1. 既存のゲームデザイン論の「大統一」

![ゲーム開発の大統一理論_01-00_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/4ab227eb-5bec-4765-b09c-5742f1786082.avif)

こんにちは。突然ですが、あなたは「面白いゲームを作りたい」と思ったとき、どんな情報を頼りにしていますか？
世の中には素晴らしいゲームデザイン論が溢れています。「ゲームとは面白い意思決定の連続である」というシド・マイヤーの有名な言葉や、「日常から切り離された特別な空間（マジックサークル）を作るべきだ」という理論など、あなたも一度は耳にしたことがあるかもしれません。

しかし、こう思いませんか？ **「なるほど、それは正しいのだろう。でも、そもそも『なぜ』それが面白いと人間は感じるのだろう？」** と。

表面的なテクニックやルールだけを学んでも、本質的な「面白さの源泉」が分かっていなければ、本当に人を熱狂させるゲームは作れません。実は、先ほど挙げたような数々のバラバラに見えるゲームデザイン論は、 **根本的な「ひとつの法則」** に統合することができます。

今回は、 **進化論と脳科学の観点から、ゲームの面白さを論理的に計算し、設計するための「大統一理論」** を解き明かしていきましょう。

## 2. 私たちの脳は「20万年前の原始時代」から変わっていない

![ゲーム開発の大統一理論_01-01_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/803bbcd6-3a17-44de-b97a-4c881ae5b4d8.avif)

なぜゲームデザインに生物学が必要なのでしょうか？ それは、 **人間の脳のハードウェアが、狩猟採集を行っていた石器時代の環境からほとんど進化していない** からです [^1]。

私たちの脳は、現代の複雑な社会システムではなく、 **「原始の世界で起きた問題（生存と生殖に関する脅威）を解決する」** ようにできています。ゆえに、現代のデジタルなエンタメであっても、理屈ではなく「原始的な本能」を直接刺激する設計でなければ、人間の心は根本から動かないのです。

## 3. 人間の根源を理解する：「8つの基礎本能」

![ゲーム開発の大統一理論_01-02_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/334483c3-f8ac-4811-b234-0100e79932a0.avif)

原始の脳に刻まれた「生存と生殖」に起因する欲求は、大きく **8つの基礎本能** に分けられます [^2]。
少し唐突に感じるかもしれませんが、これらは私たちが普段、無意識のうちに商品を買ったり、何かに熱中したりする際の「モチベーションの源泉」です。それぞれの本能がどのようなもので、現実のどんな商品で満たされているのか、表にまとめてみましょう。

| 基礎本能 | どんな本能か？（生存・生殖への機能） | 訴求されている商品やサービスの例 |
| :--- | :--- | :--- |
| **安らぐ** | 心身の危険から離れて、不安や恐怖から逃れようとする本能 | 生命保険、健康食品、昔ながらの定番ブランド |
| **進める** | 明確なゴールを設定し、前進している感覚（進捗）を得て喜ぶ本能 | 語学アプリ、ポイントカード、スタンプラリー |
| **決する** | 自分の行動や環境を自律的に決定し、コントロール感を得る本能 | オーダーメイド商品、DIYツール、旅行の計画 |
| **有する** | 生存に有利な物や情報を蓄積し、失う不安を回避しようとする本能 | 期間限定商品、タイムセール、情報まとめサイト |
| **属する** | 特定のコミュニティに所属し、仲間との一体感で安心を得る本能 | SNS、オンラインサロン、スポーツ観戦 |
| **高める** | 集団内でより高い地位を獲得し、他者から尊敬されたい本能 | 会員制限定サービス、高級外車、プロフェッショナル資格 |
| **伝える** | 自分の優秀な特性（センスや知性）を周囲へアピールしたい本能 | SNSの「映え」消費、有名レストラン、エステや化粧品 |
| **物語る** | 自分の人生や行動に大きな意味や一貫性を感じたい本能 | ドキュメンタリー映画、推し活（アイドル応援）、エコツーリズム |

ここで、先ほどの既存理論を回収しましょう。「面白い意思決定」とは、結局のところ **『決する・物語る本能』** を満たす行為であり、「マジックサークル」とは、安全が保障された空間で **『属する・安らぐ本能』** を機能させるための装置に過ぎません。すべての理論は、この「8つの本能」の枠組みに大統一できるのです。

さらに、訴求する本能の数は多ければ多いほど良いというデータがあります。Bain & Companyの大規模調査によれば、 **4つ以上の本能（価値要素）を満たすプロダクトは、そうでないものに比べ顧客推奨意向が跳ね上がる** ことがわかっています [^3]。

次回の【実践編】で解説する名作インディーゲームたちも、この本能を驚異的なレベルでカバーしています。

*   **『Undertale』** ：誰も倒さなくていいRPG。プレイヤーの選択で物語が分岐し、モンスターとの対話や平和的な解決が可能。敵を倒すか見逃すかを自ら選べる（ **「決する」** ）、世界の謎を紐解く（ **「物語る」** ）、キャラクターたちと対話で仲良くなる（ **「属する」** ）、地上へ帰るために攻略を進める（ **「進める」** ）、素晴らしい音楽を味わう（ **「有する」** ）、シンプルなドット絵で安心する（ **「安らぐ」** ）。
*   **『Vampire Survivors』** ：移動のみで自動攻撃を行うサバイバルゲーム。迫りくる無数の敵を倒して経験値を集め、キャラクターを極限まで強化していく。移動のみの簡単な操作で（ **「安らぐ」** ）、迫りくる敵を倒し続ける（ **「進める」** ）、落ちた経験値や宝箱をかき集める（ **「有する」** ）、レベルを上げて自機を極限まで強化する（ **「高める」** ）、数ある武器の中から最強の組み合わせを構築する（ **「決する」** ）。
*   **『Papers, Please』** ：架空国家の入国審査官となるゲーム。書類の矛盾を見抜く単調作業と、家族を養うため道徳的ジレンマに直面する。審査官として給料を稼ぎ家族を養う（ **「有する・属する」** ）、入国を通すか否かで他者の運命を左右する（ **「物語る・決する」** ）、テロリストや密輸業者の侵入を未然に防ぐ（ **「安らぐ」** ）。

これらの事実から、私たちはゲーム開発における **「大前提」** を定義できます。
**「ゲームにおける報酬とは、本能を訴求できる度合いである」** と。

## 4. 脳は「報酬そのもの」より「報酬の予感」に熱狂する

![ゲーム開発の大統一理論_01-03_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/b1ccfe16-79a7-4dfe-b709-3f1c35735baf.avif)

「なるほど、ゲームデザインの正体は分かった。プレイヤーの8つの本能をガンガン刺激して、報酬を与えまくれば最高のゲームになるんだな！」
あなたは今、そう思っていませんか？ 

では、質問です。 **あなたはそのようにして作った確実に面白いゲームが、面白くなるまでに2時間かかるとしてもプレイしますか？** 

多くの場合、答えはノーでしょう。実は、人間の脳は **「報酬そのもの」** よりも **「報酬の予感（期待）」** に対して最も熱狂するようにできています [^4]。
Fiorilloら(2003)の霊長類を用いた実験によると、報酬が確実に得られるときよりも、 **「成功するか失敗するか分からない（不確実性が最大となる50%の確率）」** ときに、ドーパミンニューロンは最も強く持続的に活動し、脳は最大の興奮状態に達することが示されています [^5]。

原始の世界では、いつ獲れるかわからない遠くの巨大な獲物より、目の前ですぐに結果がわかる小動物の狩り（目先の報酬）を優先する方が、当座の飢えをしのぐ生存戦略として圧倒的に適応的でした（双曲割引） [^6]。さらに、その狩りが成功するか失敗するか分からない（不確実性がある）からこそ脳は興奮し、次も狩りに向かう強い動機が生まれます。
だからこそ私たちは、2時間後に確実に感動できる名作映画よりも、すぐに見られて面白いかどうかわからないショート動画をダラダラ見続けて3時間ほど食いつぶしてしまうのです。

この「報酬の予感」を煽り、プレイヤーの集中力を高めるための3つのメソッドを紹介します。

1.  **スピード感をだす（小刻みな配当）**
    *   **根拠** : Kobayashiら(2008)の研究によると、報酬への遅延が短い（即時報酬）ほど、ドーパミンニューロンの反応は強くなります [^7]。
    *   **具体例** : 数時間後のエンディング（大きな報酬）ではなく、敵を倒した瞬間に経験値バーが伸びる、コインが弾け飛ぶなど、数秒単位で小刻みにフィードバックを与え続けましょう。
2.  **適切な難易度設定**
    *   **根拠** : Wilsonら(2019)の論文によると、学習効率と集中力を最大にするのは「成功率80〜85％（失敗率15％前後）」の難易度です [^8]。
    *   **具体例** : 常に「いけるかもしれない（不確実性がある）」という予感を煽る、ギリギリの戦闘バランスを設定します。
3.  **不毛タスクを排除する**
    *   **根拠** : Blunt & Pychyl(2000)の調査によると、「不毛タスク（報酬に意味を感じられない作業）」と「難易度エラー」は、集中力をキープできない人にありがちな二大要素です [^9]。
    *   **具体例** : たいしてうまみのない「お使いイベント」をプレイヤーにこなさせるなどの不毛な作業の押しつけは、極限まで減らさなければなりません。

## 5. 面白さのモデル化：強化学習の数式で読み解く継続率（リテンション）

![ゲーム開発の大統一理論_01-04_image.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/e4ca0893-73bd-43a0-a41e-fd3d9021a947.avif)

前章では、プレイヤーを没入させるには「報酬の予感」とそれを高める3つのメソッドが重要であるとお話ししました。では、この「予感（期待）」をゲームの開始から終了まで高く保ち続け、明日も明後日も遊び続けてもらう（この割合を **リテンション（継続率）** と呼びます）には、全体をどう設計すればいいのでしょうか？

実は、「なぜプレイヤーは途中で飽きてゲームをやめてしまうのか」というメカニズムは、数学的なモデルで明確に説明することができます。ここで、人工知能の「強化学習」で使われる価値更新の数式（デルタ・ルール）を使って、人間の期待値の推移を計算してみましょう。人間の脳の学習プロセスが実際に以下の数式に合致することは、Leeら(2020)の認知科学の実験でも証明されています [^10]。

少し難しそうな数式ですが、身近な **「連続ドラマの視聴」** に置き換えると非常に直観的でシンプルです。

$$Q_{t+1} = (1 - \alpha)Q_t + \alpha R_t$$

*   **$Q_{t+1}$** ： 次の回に対する「期待値（報酬の予感）」
*   **$Q_t$** ： 今までの「期待値」
*   **$R_t$** ： 今回の「評価（現実の報酬）」
*   **$\alpha$** ： 学習率（直近の経験をどれくらい重視するか。今回は **0.8** とします）

簡単に言えば、 **「次の期待値は、今までの期待値に、今回の面白さをブレンドして上書きされる」** ということです。

ここで、 **全4話、総得点が同じ30点** になる2つのドラマがあるとします。ただし、 **「視聴者は、次への期待値（ $Q$ ）が 7.0点 を下回った瞬間に見るのをやめてしまう（離脱する）」** というシビアなルールを設定します。

*   **パターンA（乱高下するドラマ）** ：評価が 10点 → 4点 → 8点 → 8点 （計30点）
*   **パターンB（安定して優秀なドラマ）** ：評価が 7.5点 → 7.5点 → 7.5点 → 7.5点 （計30点）

この2つの期待値推移を、Pythonを使ってシミュレーション・可視化してみましょう。

![drama_expectation_simulation_jp.avif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4415366/2f157c4a-9a2a-4d4e-a16d-0a32132fcdbe.avif)

結果はどうなったでしょうか。
パターンAは、2話目で「4点」という退屈な回を出したせいで、 **次への期待値が「5.2点」まで急落し、離脱ライン（7.0点）を割ってしまいました。** つまり、その後の3話と4話がどれだけ面白く（8点）ても、視聴者はもう見てくれないのです。
一方、パターンBは常に7.5点の期待値をキープし、無事に最後まで見てもらえます。総得点は同じなのに、結果は天と地ほど違います。

この数式は、前章で紹介したメソッドがいかに重要かを物語っています。
ゲームのテンポが悪ければ「スピード感」が損なわれ、難易度が崩れれば「85%の適度な不確実性」が失われ、お使いクエストのような「不毛タスク」を入れれば、今回の報酬（ $R_t$ ）は底辺まで落ち込みます。
 **一度でもひどい退屈を与えて期待値を落としてしまうと、その後でどれだけ挽回してもプレイヤーは二度と戻ってこない** のです。

## 6. 第1回のまとめ

ここまでの話をまとめましょう。
私たちの脳は原始時代から変わっていません。だからこそ、ゲームは「8つの本能」を多く満たすことが重要です。しかし、脳は報酬そのものより、目先の不確実性（スピード感・難易度85%・不毛タスクゼロ）がもたらす『報酬の予感』の連続に支配されています。そして数式が示す通り、一度の退屈が致命傷になります。

結論として、 **「原始の本能に基づく報酬を用意するだけでなく、報酬の出し方に気を配り、報酬の数式を常に高い値でキープすることが肝心」** なのです。

次回は、この厳酷な脳のメカニズムに対応するため、ゲームからいかにノイズを消し去り洗練させるかという **「問いの力（実践編）」** について解説します！
