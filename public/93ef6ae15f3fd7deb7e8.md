## 科学的根拠に基づく効率的な勉強法で、基本情報技術者試験を20日で攻略した話（シラバス9.0版）

## はじめに

華麗なる先延ばしの結果、2026/4/4(土)からカリキュラムの最終日である2026/4/26(日)にむけて約20日で基本情報技術者を取らねばならなくなりました。

しかし、科学的に認められている効率的な勉強法を活用してなんとか20日で合格できたので、その方法を紹介したいと思います。

この方法は他の勉強でも参考になると思いますので、ぜひ最後までお読みください。


::: note warn
**注意**
筆者は大学でそこそこコンピュータ科学を学んでいます。全くの未経験からの20日合格は難易度が高いため、一つの「効率化モデル」として参考にしてください。
:::

## 0. そもそも基本情報技術者試験って何？

まず、「**[彼を知り己を知れば百戦殆からず](https://ja.wikipedia.org/wiki/彼を知り己を知れば百戦殆からず)**」ということで基本情報技術者試験（シラバス9.0版）について説明します。

[基本情報技術者試験（シラバス9.0版）](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kpe-att/syllabus_fe_ver9_2.pdf)は、ITの基礎知識と論理的思考力を証明する国家資格です。

合格率は **40~50%** ですが、就職の際の前提条件となるなど、ITエンジニアとしての登竜門的な国家試験といえます。

* **構成**: 
    * **科目A**: 四肢択一式。広範な知識（テクノロジ・マネジメント・戦略）が問われる
    * **科目B**: 多肢選択式。アルゴリズムとプログラミング、情報セキュリティの応用力が問われる
* **合格基準**: 各科目1,000点満点中、600点以上で合格 

## 1. 効率のいい勉強法とは？

20日間で基本情報技術者試験に合格するのは難しいので、**科学的に最強と言われる3つの勉強法**を使っていきます。

### 1-1. 戦略的リソース活用法

**メタ認知**を効かせることで、効率よく学習資源を活用することができるようになると言われています。

### 1-2. 検索練習

「**がんばって思い出す**」要素が入った学習法のこと。

意識して情報を思い出す勉強法全般を指しており、例えば、

- フラッシュカード（anki）
- 模擬テスト（過去問道場）
- 赤シート（公式テキスト）

が挙げられます。

多くのメタ分析で効果が実証された**記憶定着の王者**で、知識が問われる科目Aに必須のテクニックです。

こちらも詳しくは[学習法の統一王者、それは「検索練習」](https://yuchrszk.blogspot.com/2016/11/blog-post_30.html)を参照してください。

::: note info
[anki](https://apps.ankiweb.net)は忘却曲線に従い、適切なタイミングで復習することができる最強のフラッシュカードアプリです。
使い方は、[【すべての勉強する人たちへ】最強の暗記アプリAnkiについてご紹介します](https://note.com/noa813/n/n103da9c65f01)をどうぞ。
:::

### 1-3. 教えるつもり勉強法

「**人に教えるつもりで学ぶ**」要素が入った学習法のこと。

「他の人に教えなきゃ！」と思うことで、

- モチベーションアップ
- 情報の体系化がすすむ
- 記憶に残る

という効果が見込めます。

私の場合は「機械オンチの妹に説明するなら……」と考えることで、科目Aの知識の定着や科目Bの論理の理解に活用しました。

こちらも詳しくは[勉強の効率を挙げるには「人に教えるつもりで学ぶ」こと](https://yuchrszk.blogspot.com/2014/08/blog-post_43.html)を参照してください。

## 2. 勉強計画

以上の内容を鑑み、**メタ認知**を働かせながら最適な学習プランを考えます。

といっても一人で考える必要はなく、**先程のMarkdownや基本情報技術者試験についての情報を[NotebookLM](https://notebooklm.google/)（ソースを読み込んで動くGoogleのAI）にインプットして、相談しながら**考えていきます。

その結果、私は以下のようになりました。

**基本的に毎日、科目A対策**

- PCで[基本情報技術者試験　過去問道場](https://www.fe-siken.com/fekakomon.php)（過去問解きまくれるやつ）を解きまくる
- わからなかった問題は解説読んだ後、スクショ（`ctrl + shift + S`）して、ankiに入れていく
- 寝る間に、ankiに溜まったカードをひたすら捌く
- スキマ時間（移動時間とか）に[テキスト](https://www.amazon.co.jp/令和07年-イメージ＆クレバー方式でよくわかる-かやのき先生の基本情報技術者教室-栢木-厚/dp/4297145340)を読んで、「妹に説明するなら……」とか考えながら、理解を進める
- ぐでーってしたいときは、 [ゆるコンピュータ科学ラジオ](https://www.youtube.com/@yurucom)（ゆるく楽しくコンピュータ科学を学べるラジオ）を見る

**まとまった時間が取れるときに、科目B対策**

- テキストに載っている問題を解いて、解説を読む
- 公開されている科目Bの過去問解いて、[すーさんのYouTube動画](https://www.youtube.com/watch?v=wFpyeWto8Og)見ながら理解する

## 3. 勉強の進捗

しっかり記録はつけていませんでしたが、3日ごとに見るとだいたい以下のような流れで進んでいきました。

| 日付 | やったこと | 感触 |
|---|---|---|
| 4/4 | 過去問道場で50問くらい解く | 正答率55%くらい |
| 4/7 | 過去問道場で50問くらい解く | 正答率60%くらい |
| 4/10 | **一日中酒を飲む（？！）** | **進捗ゼロ** |
| 4/13 | 初めて科目Bを解く | 科目Bはプログラミング経験でゴリ押しできそう |
| 4/16 | 過去問道場で25問くらい解く | 正答率60%くらい |
| 4/19 | 過去問道場で25問くらい解く | 正答率60%くらい - なかなか結果が出ずに不安になる |
| 4/21 | イベントの移動時間でテキスト読む | 正答率65%くらいだが、だんだん理解できてきたような気がしてくる |
| 4/24 | 科目Bの過去問解いてすーさんの動画見る | 科目Bは8割くらいとれそう |

途中明らかにサボっていますが、淡々とやるべきことをやっていくという姿勢が重要だと思います。

## 5. まとめ

### 感想

中学・高校とは違い、ankiのようなITツールを組み込んで、**自分で決めた効率的な勉強**ができたのが楽しかったです。

一方で、結局PCだけで完結したので、**ankiの4,000円のモバイル版の購入**は不要だったと感じました。

### 役立ちポイント

正直、勉強前・中は**なんの役に立つのかあまり理解していませんでした。**

しかし、現在取り組んでいる卒業研究において、リスクマネジメントの知見を活かして重要なデータを分散させたり、モジュール分割の知見を活かして機能的なコーディングをしたり、**めちゃくちゃ役に立っています。**

結局、基本情報技術者試験を勉強して本当に良かったと感じているので、みなさんもぜひ挑戦してみることをおすすめします。
